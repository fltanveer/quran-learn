# কুরআন বুঝে পড়ি (Quran Learn)

A personal, offline-first PWA that helps a Bangla speaker understand the Quran while reciting it.
The full spec is in [quran-app-build-spec.md](quran-app-build-spec.md).

Scope: Al-Fatiha and all of Juz Amma (78 to 114). Add more surahs in `data/scope.json` (`extra_surahs`), then run `npm run data`.

## Commands

```bash
npm install
npm run download      # fetch raw sources into /raw (skips files that exist; add -- --force to refetch)
npm run build-data    # build /public/data from /raw; fails on Tanzil/Corpus word-count mismatch
npm run data          # both of the above
npm run dev           # local dev server (service worker is off in dev)
npm run build         # static export to /out, flattens Next segment files, writes out/sw.js
npm start             # serve /out locally
```

Deploy `/out` to any static host. See "Licenses" before making it public.

## Features

| Phase | What |
| --- | --- |
| 1 | Recite Mode with word meanings, root/pattern coloring, Word card, Ayah sheet (translations, Al-Mukhtasar, notes), per-ayah audio, offline PWA |
| 1+ | Bangla pronunciation (উচ্চারণ) per ayah and per word, generated by `scripts/bangla-pron.ts` |
| 2 | FSRS review (`/review`), known words driven by review state, pattern families with quizzes (`/patterns`) |
| 3 | 10 classical tafsirs (6 Arabic, 4 Bangla) in the Ayah sheet; summary pipeline; notes shown again under their ayah |
| 4 | Practice tab: record an ayah, play it after the qari, word check with browser speech recognition (best effort) |
| 5 | All of Juz Amma, plus any surah listed in `data/scope.json`; choose your salah surahs for the progress ring |

## Tafsir summaries (Phase 3)

Summaries are made outside the app with an AI tool, one tafsir record at a time, then imported.

```bash
npm run summaries:export -- ar_saadi 1 112   # writes summaries-work/ar_saadi/001/<ayah>.md
# paste each .md into the AI tool; save the JSON answer next to it as <ayah>.json (same name)
npm run summaries:import                    # validates and merges into public/data/summaries/NNN.json
```

Source slugs: `bn_mokhtasar`, `ar_saadi`, `ar_ibn_kathir`, `ar_muyassar`, `ar_tabari`, `ar_qurtubi`, `ar_baghawi`,
`bn_ibn_kathir`, `bn_ahsanul_bayaan`, `bn_zakaria`, `bn_fathul_majid`. Imported summaries are `unreviewed`;
mark each one checked in the app after comparing it with the original.

## Data sources

All sources, licenses, versions and download dates are in `public/data/sources.json` and on `/about`.
Quran, translation and tafsir text is stored exactly as downloaded.

| Content | Source |
| --- | --- |
| Arabic text | Tanzil Uthmani 1.1 (XML, bismillah kept as a separate attribute) |
| Morphology | Quranic Arabic Corpus 0.4, from the verbatim CLTK mirror (the official page asks for an e-mail address) |
| Translations | QuranEnc `bengali_zakaria`, `bengali_rwwad`; Tanzil `bn.bengali`, `bn.hoque` |
| Short tafsir | QuranEnc `bengali_mokhtasar` (Al-Mukhtasar), bundled offline |
| Classical tafsir | Quran.com API v4 (same data as QUL, whose downloads need a login); cached on first open |
| Word by word | Quran.com API v4 (Bangla and English) |
| Pronunciation | Generated by rule from Tanzil text; approximate |
| Audio | EveryAyah, Mishary Alafasy 128 kbps, streamed |

## Licenses

Personal use is covered. Before deploying to a public URL: Tanzil translations are non-commercial only, and the
Bangla classical tafsirs (and QUL / Quran.com data in general) need publisher permission to publish.

## Files to review by hand

- `data/root-meanings.json`: Bangla core meaning per root. Empty until filled; the build copies values into `roots.json`.
- `data/patterns.json`: Bangla pattern names. Set `reviewed: true` after checking each one.
- `data/surah-names-bn.json`: Bangla transliterated surah names (not from a downloaded source).
- Pronunciation: `npx tsx scripts/_pron-check.ts 001 112` prints it for review.

## Local data

Progress, known words, review cards, notes, quiz scores and settings live in IndexedDB (Dexie) on the device only.
Practice recordings stay in memory and are never saved or sent.
